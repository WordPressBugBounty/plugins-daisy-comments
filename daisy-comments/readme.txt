Disables comment functionality and hides all existing comments from your WordPress website.

== Description ==

Daisy Comments completely disables all comment functionality on your WordPress site, including:

* Disables comment forms on all posts/pages
* Hides all existing comments from display
* Removes comment feeds
* Cleans up admin area by removing comment-related menus and widgets
* Provides beautiful settings panel with toggle control

== Installation ==

1. Upload the `daisy-comments` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Visit Settings -> Daisy Comments to configure

== Frequently Asked Questions ==

= Will this delete my existing comments? =

No, it only hides them from view. Your comments remain in the database.

= Can I selectively disable comments? =

Currently, the plugin disables comments site-wide. Future versions may include per-post type controls.
